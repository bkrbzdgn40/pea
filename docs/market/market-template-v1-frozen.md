# Market Template v1 — Frozen

Status: feature-complete template pending integration into the current main
movement-analysis baseline.

The template is frozen after the accessibility, visual-budget, dependency, and
profile gates. Further work requires a separate product decision.

Changes that require reopening scope include:

- remote catalog loading or a web operations console
- persistent carts
- product search, favorites, recommendations, promotions, or reviews
- addresses, checkout activation, payments, orders, stock, delivery, or returns

Bug fixes, accessibility corrections, localization corrections, and verified
performance regressions may be handled without expanding scope.
