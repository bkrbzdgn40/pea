# P1.3 start-pose readiness package

This package aligns the preparation reference and readiness evidence for:

- Stationary Lunge
- Bent-Knee Leg Raise
- Frog Pump
- Floor Chest Press

The changes are preparation-only. Rep thresholds, scoring, tempo, and live-analysis lifecycle are unchanged.

## Readiness decisions

- Stationary Lunge uses a wider split-stance reference and can recover a foot anchor from heel/foot-index landmarks when one ankle is occluded.
- Bent-Knee Leg Raise accepts one reliable bent knee in the side view instead of averaging a distorted far-side leg.
- Frog Pump checks horizontal torso and joined feet; knee opening is intentionally instructional because a side-view 2D projection cannot reliably validate out-of-plane hip rotation.
- Floor Chest Press accepts one reliable bent elbow and knee, matching the camera-near side used by live analysis.
- Framing no longer requires heel/toe or head landmarks that are not consumed by these exercise analyses.
